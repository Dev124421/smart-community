# Smart Community

A real-time chat platform where people can create communities, talk in channels and DMs, and stay safe with AI-assisted moderation.

## What it does
- Create or join communities with invite links
- Chat in channels, DMs, and group chats in real time
- Share files, react to messages, reply, and mention people
- An AI service flags toxic messages for moderators to review
- A human always makes the final call
